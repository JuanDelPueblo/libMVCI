# MVCI hardware-free test manifest.
#
# This is the single source of truth for the offline regression set. It is
# read by CMakeLists.txt (CTest targets) and by tools/check-offline.sh (its
# direct-compiler and sanitizer paths), so the three paths cannot drift.
#
# One test per line. Fields are separated by '|':
#
#   target | ctest name | sources | defines | include dirs | wraps | hosts | note
#
# sources, defines, include dirs and wraps are space-separated and relative to
# the repository root. Use '-' for an empty field. A field must not contain
# ';' (CMake reads it as a list separator). hosts is:
#
#   any    - build and run on every host
#   posix  - every host except Windows
#   gnu    - an ELF host whose linker supports --wrap (Linux and similar)
#
# note is a short statement of what the test proves; for a limited host it
# names the missing capability. Every test runs with no arguments and needs no
# adapter, provider, vehicle, network or proprietary runtime.
#
# To register another offline regression, add its source file and one line
# here. CMake does not glob the test directory: a missing source is a
# configure error.
#
